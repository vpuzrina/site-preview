# site-preview

Preview of the next version of https://vpuzrina.github.io, built from the `v2-papers` branch of
[vpuzrina/vpuzrina.github.io](https://github.com/vpuzrina/vpuzrina.github.io).

- Live at https://vpuzrina.github.io/site-preview/ (every page has `noindex`).
- Pages is not enabled in this repository, so the preview is built and published by the deploy workflow
  of vpuzrina/vpuzrina.github.io, into the `/site-preview/` folder of the main site.
- The workflow here is manual-only and works once Settings → Pages → Source is set to **GitHub Actions**.

Nothing else lives in this repository. Delete it once the main site has switched over.
